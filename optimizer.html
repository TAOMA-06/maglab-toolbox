模块三 · CS2 电脑运算延迟优化

降低 CS2 右上角帧数左侧的
【最高 ~ 毫秒】

该数值反映 CPU 每帧运算耗时（frametime / CPU frame time）。数值越高，鼠标操作到屏幕反馈的电脑运算延迟越大。 本工具生成 Windows 一键优化脚本（电源计划、游戏模式、GPU 调度、CS2 启动参数等），降低运算延迟，提升帧次稳定性。

—CPU 逻辑核心
—设备内存
—屏幕
—平台

重要： 浏览器无法直接修改系统设置，因此生成的 .bat 脚本请下载后右键 → 以管理员身份运行。 执行完毕后重启电脑，再在 Steam → CS2 属性 → 启动选项中填入建议参数，启动 CS2 观察右上角帧数左侧毫秒数是否下降。

优化项目

ONE-CLICK SCRIPT
⚠️ 这里的开关只是“你要优化什么”的选择，不是系统实际状态。网页无法读取 Windows 设置，刷新后开关会保持你上次的选择。要验证优化是否真正生效，请运行同目录下的 检查优化状态.bat。
电源计划 → 高性能 / 终极性能
防止 CPU 频率下调，保持 CS2 单核运算频率，降低帧耗时。
影响：高
Windows 游戏模式 → 开启
让 Windows 在游戏时优先分配 CPU/GPU 资源，减少后台任务抢占。
影响：中
硬件加速 GPU 调度 → 按显卡分代设置
40/50 系开（吃 NVIDIA Reflex），10/20 系关（帧时间更稳），30 系两边都测。需 Win10 2004+ / Win11，改完重启生效。
影响：中/视机型
CS2 启动参数优化
在 Steam 属性中设置启动选项（-freq 按你显示器刷新率自动生成，不写死）。
影响：高
CS2 进程优先级 → 高
游戏运行时将 cs2.exe 优先级设为“高”，减少被后台进程抢占 CPU 时间片。
影响：中
清理系统临时文件
清空 %TEMP%，释放磁盘空间。对帧耗时基本无直接影响，只做清理。
影响：低
鼠标增强指针精确度 → 关闭
FPS 必关项。关闭 Windows 指针加速，保证游戏内 1:1；Windows 鼠标速度保持 6/11，需注销或重启生效。
影响：高
NVIDIA Reflex → 游戏内开启+增强
CS2 设置 → 视频 → 高级 → NVIDIA Reflex 低延迟。需 GTX 10 系以上 + 新驱动；驱动里低延迟模式保持默认即可。
影响：高
禁用 CS2 全屏优化
cs2.exe 右键 → 属性 → 兼容性 → 勾选。独占全屏下延迟更稳，已用全屏模式的玩家优先做。
影响：中
内存完整性 / VBS → 关闭（可选）
Windows 安全中心 → 设备安全性 → 内核隔离 → 关，需重启。这会降低虚拟化安全隔离，个人游戏机可接受，介意者跳过。
影响：低-中

💻 笔记本专用优化

展开
独显直连 / 强制独显输出
笔记本混合显卡（NVIDIA Optimus / AMD 混合显卡）强制独显直输，绕过核显，降低帧提交延迟。需在 NVIDIA 控制面板 / AMD 驱动中设置 CS2 为“高性能 NVIDIA 处理器”。
影响：高
插电时最小处理器状态 100%
防止笔记本 CPU 在游戏中降频节能，保持单核运算频率，降低 CS2 帧耗时。
影响：高
禁用 USB 选择性暂停
防止笔记本 USB 接口进入低功耗导致鼠标轮询延迟或掉线，保持鼠标稳定输出。
影响：中
禁用 PCI Express 链路状态电源管理
关闭 PCIe ASPM 节能，避免独显/硬件在低负载时降频，提升帧稳定性。
影响：中
关闭 Windows 快速启动
只影响开机与驱动初始化，不影响游戏内帧耗时；开关机慢半拍属正常。
影响：中
禁用 SysMain（Superfetch）
SSD 上基本无增益；只有机械盘或内存常年吃满时有用。默认不勾，按需开。
影响：低
禁用 Windows 搜索索引
开始菜单搜索会变慢；只为压后台负载，介意者跳过。
影响：低
执行顺序建议： 1) 下载并以管理员身份运行生成的 .bat → 2) 重启电脑 → 3) Steam 设置 CS2 启动参数 → 4) 启动 CS2，打开 cl_showfps 2 观察右上角帧数左侧毫秒数。
