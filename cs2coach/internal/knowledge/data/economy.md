# CS2 经济规则（公开通行值）

## 回合收入
- 胜方常规获胜（歼灭 / 时间耗尽）：每人 $3250。
- T 下包获胜（C4 爆炸）：每人 $3500。
- CT 拆包获胜：每人 $3500。
- 败方补偿（连败递增）：$1400 + $500 × 当前连败数，封顶 $3400（梯度：1400 / 1900 / 2400 / 2900 / 3400；赢下任意回合后连败清零）。
- T 下包奖励：C4 一旦安放，T 全员每人 +$800，即使回合输掉也照发。
- 现金上限：每人最多持有 $16000。

## 半场
- 常规赛制 MR12，12 回合后半场换边。
- 换边后双方现金重置为 $800、连败计数清零（与开局一致）。

## 买型判定（人均装备值）
- 全起 full：人均装备值 ≥ $4750。
- 强起 force：$2500 – $4750 且本回合有花钱；其中 ≥ $3800 记半起 half。
- 经济局 eco：人均装备值 < $2500。
- 强起的本质是「用半套装备打对手全起」：这波打不过，输了下一把更穷，所以只在能换到东西时才强起。

## 装备参考价（买枪估算用）
- 步枪：AK-47 约 $2700，M4A4 约 $3100，M4A1-S 约 $2900（M4 系约 2900-3100）。
- 护甲：全甲（防弹衣 + 头盔）$1000，单防弹衣 $650，头盔 $350。
- 拆弹器 $400。
- 道具：烟雾弹 $300，闪光弹 $200，高爆手雷 $300，燃烧瓶（T）$400 / 燃烧弹（CT）$600。
